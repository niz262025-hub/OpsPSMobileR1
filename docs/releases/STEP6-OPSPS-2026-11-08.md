- Require explicit verified paid access; an absent/unknown access mode is no longer interpreted as paid. Trial admission requires active central entitlement, the existing verified staging database adapter, an explicit enable flag and unexpired policy-version-1 metadata. The runtime no longer defaults that enable flag to true. No hosted function/environment/database was changed.
- Retain central login, local session revocation and return-to-MYOPS navigation. Activity polling records only visible trusted interactions, sends them once, preserves interactions arriving during an in-flight refresh and prevents overlapping refreshes/stale-session effects.
- Retain and consolidate trip/product/order loading fixes. Fix a TypeScript error in the imported loading test.
- Add a language selector to the shared tab layout and connect fixed copy in the primary shopper screens and trip creation to the dictionary. English, Malay, Simplified Chinese and Tamil are supported; the existing Hindi dictionary remains available for compatibility. Legacy BM/standard locale preferences normalize, an explicit choice wins over late hydration, unavailable browser storage still permits selection in memory and persistence writes are ordered. User-entered data and API enums are unchanged. This is not a claim that all legacy screens/backend errors have been translated.
- Legacy landing dictionary offers now match central MYOPS: seven-day trial, first 100 RM29 once, two apps RM49/month, all apps RM79/month. No app-specific checkout or new recurring commission was introduced.
- Add the existing atomic-trial database regression script to required web CI.
